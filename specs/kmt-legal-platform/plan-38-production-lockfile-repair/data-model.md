# Data Model: Production Lockfile Repair

## Application data

No application entity, database table, field, index, migration, seed, or retention behavior changes.

## Delivery artifact

### Dependency lock

- **Artifact**: `package-lock.json`
- **Owner**: npm 11.6.2
- **Source of intent**: unchanged `package.json`
- **Required properties**:
  - lockfile version remains compatible with npm 11.6.2;
  - all transitive dependency records required by the manifest are present;
  - resolved URLs and integrity metadata are generated by npm;
  - a subsequent `npm ci` accepts the artifact without modifying it.

## State transition

`out-of-sync committed lockfile` → `npm-generated synchronized lockfile` → `clean-install verified` → `build verified` → `server deployed` → `live health and sitemap accepted`

If any step fails, the state does not advance and the existing live release/former-domain fallback remains in place.
