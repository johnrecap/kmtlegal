## Adaptation boundaries

Source-inspired composition is distinguished from copied code. This preview phase uses original semantic HTML/CSS/JavaScript and existing KMT assets. Vendor installation commands are not run. Reusable official React components can be evaluated again after the owner chooses a direction; this preview does not select replacements for owner-locked production primitives.

The same fixed sample conversation, 14 dated days, weekly closure, booked day, partial closure, Cairo-labelled slots and sample customer drive all five directions and the actual-app baseline. New preview-only visible text is centralized in shared/preview-copy.js (gallery-only labels in shared/gallery.js). No testimonials, online-staff availability, prices or success metrics are invented.
